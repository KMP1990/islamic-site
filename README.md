# طريق الهدى — تطوير الحسابات والإدارة 2.0

موقع عربي ثابت. هذه النسخة تطوّر أنظمة الحسابات، لوحة المطور، الأخبار والإعلانات الموجودة.

## التشغيل

لا يحتاج الموقع إلى عملية build أو تثبيت حزم لتشغيله. انشر الملفات على استضافة static تدعم HTTPS، أو شغّله محليًا من مجلد المشروع باستخدام Python 3:

```sh
python3 -m http.server 8080
```

افتح `http://localhost:8080` ثم ادخل الموقع. صفحة التطبيق هي `dashboard.html`.
تحتاج وظائف كلمات المرور إلى Web Crypto، لذلك استخدم HTTPS أو localhost؛ لا تعتمد على فتح HTML مباشرةً من الملفات.

## الوصول إلى الإدارة

اضغط زر **v2.0 · الإدارة** في الرئيسية أو استخدم **Ctrl + Alt + D**.
عند أول دخول اختر كلمة مرور للمطور من 10 إلى 128 حرفًا وأكّدها. لا توجد كلمة مرور افتراضية.
كلمة مرور المطور مستقلة عن حساب المستخدم. تنتهي جلسة الإدارة بعد 15 دقيقة من عدم النشاط.

## الحسابات

- تسجيل باسم المستخدم أو البريد، مع خيار «تذكرني» لمدة 30 يومًا؛ بدونه تنتهي الجلسة بعد يوم أو عند إغلاق جلسة المتصفح.
- كلمات مرور PBKDF2-SHA-256 مع 600,000 دورة وsalt عشوائي لكل كلمة مرور.
- ترقية التخزين القديم عند أول دخول ناجح، وقفل المحاولات المتكررة لمدة دقيقتين.
- احفظ رمز الاستعادة عند التسجيل. استعادة كلمة المرور تستلزم الرمز وتصدر رمزًا جديدًا بدل القديم.
- الحسابات القديمة التي لا تملك رمزًا تستطيع توليده من الملف الشخصي بعد الدخول وكتابة كلمة المرور الحالية.
- تغيير كلمة المرور أو إيقاف الحساب يبطل الجلسات الحالية.
- تعديل الملف الشخصي، تغيير كلمة المرور، توليد رمز استعادة جديد وحذف الحساب.
- البريد حقل اختياري لتسجيل الدخول؛ لا يُرسل الموقع بريدًا ولا يثبت ملكية العنوان.

## الأخبار والإعلانات

لوحة الإدارة تضم نظرة عامة، أخبارًا، إعلانات، مستخدمين، إعدادات ونسخًا احتياطيًا.

الأخبار تدعم المسودات، الجدولة، التثبيت، التمييز، الأولوية، البحث والتصفية والمعاينة.
يمكن ترك البداية فارغة للنشر الفوري، والنهاية فارغة للنشر المستمر.
المواعيد تستخدم الوقت المحلي للمتصفح وتُراجع أثناء بقاء الصفحة مفتوحة.

الإعلانات تدعم مواضع أعلى الرئيسية وبين الأخبار وأسفل الرئيسية ونافذة منبثقة، مع تحديد الجمهور المحلي
ونص زر الرابط والأولوية والجدولة. النوافذ المنبثقة قابلة للإغلاق دائمًا.
المشاهدات تُسجّل عند تقاطع 50% من الإعلان مع نافذة العرض، مرة لكل إعلان في جلسة المتصفح.
النقرات والمشاهدات ونسبة النقر محلية وليست تحليلات لجميع الزوار.

الصور تستخدم روابط HTTP/HTTPS. الإعدادات تشمل تعطيل التسجيل، اشتراط الدخول، شريط تنبيه،
وضع الصيانة، التحكم في مواضع الإعلانات وعددها، والأخبار وتحديثها.

## البيانات والنسخ الاحتياطي

الحسابات والمحتوى والإحصاءات تُحفظ داخل هذا المتصفح فقط، ولا تتزامن مع أجهزة أخرى.
تغيير نطاق الموقع أو حذف بيانات المتصفح يفقد الوصول إلى هذه البيانات.
رفع ملفات الموقع وحده لا ينقل الأخبار والإعلانات التي كتبتها داخل متصفحك إلى بقية الزوار.

تصدير JSON يضم الأخبار والإعلانات والإعدادات فقط. لا يضم حسابات المستخدمين، رموز الاستعادة
أو كلمة مرور المطور. صدّر نسخة قبل الاستيراد؛ الاستيراد يستبدل المحتوى بعد التحقق والتأكيد.
الحد الأقصى لملف الاستيراد 2MB، وللأخبار والإعلانات 500 عنصر لكل نوع.
الصور القديمة المحفوظة كرابط data محلي لا تُقبل في الاستيراد الجديد؛ استبدلها بروابط صور.

هذه إدارة محلية، ويمكن لمن يتحكم بالمتصفح تغيير بياناته. اشتراط الدخول والصيانة حاجزان في
واجهة المتصفح. الحسابات المشتركة والصلاحيات الإدارية الفعلية ونشر المحتوى لكل الزوار تحتاج
خادمًا وقاعدة بيانات والتحقق من الصلاحيات على الخادم.

## التحقق للمطورين

لتشغيل الفحوص تحتاج Node.js حديثًا وnpm:

```sh
npm ci --ignore-scripts
npm run lint
npm run typecheck
npm test
```

`lint` يفحص ملفات الحسابات والإدارة والأمان والاختبارات، إضافة إلى صحة صياغة جميع ملفات JS
ومعالجات HTML، عدم تكرار المعرفات ووجود الموارد المحلية.
`typecheck` يفحص وحدة الأمان `js/security.js` بنمط TypeScript الصارم.
الاختبارات تستخدم Node.js وJSDOM للتحقق من الحسابات والجلسات والاستعادة والإدارة والمحتوى والاستيراد.
لا تحاكي هذه الفحوص تجربة الواجهة المرئية في متصفح حقيقي.
